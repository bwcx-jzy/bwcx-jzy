## 关于

我是蒋小小（bwcx-jzy），Java 开发者。

2018 年开源了 [Jpom](https://github.com/dromara/Jpom)：一款低侵入的构建、部署、日常运维与监控工具。
项目长期以个人维护为主，累计迭代 150+ 个版本。2026 年 2 月起暂停常规功能迭代，
安全维护继续，2026-11-07 发布了 [2.11.13 安全修复版](https://jpom.top/pages/security/2.11.13/)。

## 在做

- **[Jpom](https://github.com/dromara/Jpom) 安全维护**：跟进漏洞、发布修复版本，2.11.13 修复的最高 CVSS 为 9.8
- **[jpom.top](https://jpom.top)**：维护文档站与安全公告，源站在 [jpom-docs](https://github.com/bwcx-jzy/jpom-docs)
